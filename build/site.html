Door 3 · The case

      
The Case

      

      
Olympass rests on a framework Ganymede calls the Furqan-Zeta law: a lattice held by a few fixed constants and the Sator square, in which no information is ever deleted. This page splits it into what anyone can check, a working demonstration, and claims set beside the test that would break them.

Part B

      
Demonstration: zero deletion

      

        
        

          
Each cell's next state is a rule over its four neighbours, combined with that cell's previous state. That combination makes every step undoable. Run the lattice forward as long as you like, then backward, and it returns to its exact start. The seed is not random: it is read from the letters of the Sator square.

Part C

      
Claims, and how to break them

      
A claim earns trust by naming the result that would count against it. Each one here does.

      

        

          
C1Shown in principle

          
Zero deletion: a River lattice loses no information.

          
Test
Run the full River cube forward and back and compare fingerprints, as Part B does at small scale.

          
Would count against it
Any run that cannot return to its seed.

        

        

          
C2Control designed

          
The Sator square holds the cube stable.

          
Test
Matched runs, same seed and steps, with and without the Sator square and its letter roles. Compare drift and recoverability.

          
Would count against it
No measurable difference between the two runs.

        

        

          
C3Experiment designed

          
Names with agreed authority act as stabilising fields in the language lattice.

          
Test
Train a small model on River sequences and probe its internals, as the Othello-GPT studies did, for whether named anchors organise the representation more than plain tokens.

          
Would count against it
Probes find named anchors no more organising than random tokens.

        

        

          
C4Measurement needed

          
Solar and lunar carriers run at 3510 Hz and 1092 Hz.

          
Test
Their structure is checked in Part A. Next: name the instrument and the place where these signals should appear, then record there.

          
Would count against it
A recording at the named place shows nothing at either frequency.

F-R-Q, the root of Furqān, the criterion. It sits at the entry point and does one job: to separate, to distinguish, to make clear.

        

        

          
The Naam index

“what”, in Ganymede's Arabic dialect

namae, Japanese for name

The lookup is stored as Naam, beside its Japanese and Chinese neighbours, so a name is found through the chain of words around it.
